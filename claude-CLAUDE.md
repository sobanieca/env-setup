# Git workflow

- After you make the changes I asked for, commit them automatically. Do not wait for me to ask for a commit.
- Commit directly on the default branch (`main` or `master`). Do not create a feature branch or a worktree. If I checked out another branch myself, commit on that branch.
- Only use a feature branch or a separate worktree when I explicitly ask for one.
- Do not push automatically. Push only when I ask.

# todoer

- Use the todoer skill and its worktree workflow only when I explicitly ask to use todoer to work on a todo. For all other changes, follow the git workflow above, also in projects with a `.todoer/` folder.
